# Citation I/SP TOLD Calculator — project instructions

## Changelog

When we make a change, update the CHANGELOG file with a summary. The summary
should be two lines or less and written in ASD STE-100.

ASD-STE100 (Simplified Technical English) in practice, for the entries here:

- Use the active voice and name the thing that acts.
- Write one idea per sentence. Keep descriptive sentences to 25 words or fewer.
- Use the simple present or simple past. Avoid strings of nouns and gerunds.
- Use one approved term per concept, and use it consistently.
